Область «гемолиз» проверяется по сочетанию признаков; если данных недостаточно, результат имеет статус «не оценено» или «под подозрением», а не «подтверждено».

Жёсткие рамки (за ними значение считается ошибкой ввода, ответ 422; `config/analytes.yaml`): ЛДГ 3–50 000 Ед/л, непрямой билирубин 0–1 000 мкмоль/л, гаптоглобин 0–10 г/л, ретикулоциты 0–40 %, церулоплазмин 0,01–2 г/л.

## Что нужно решить

### 1. Границы по умолчанию

| ЛДГ, Ед/л | М: 135; Ж: 135 | М: 225; Ж: 214 | Да | Да, для детей | Гемотест; локальный референс важнее | Использовать эти значения только как fallback для взрослых. Лабораторный референс имеет приоритет. |
| Непрямой билирубин, мкмоль/л | 0 | 16,4 | Нет для взрослых | Да, для детей | СМ-Клиника | Использовать верхний проектный предел 16,4 мкмоль/л. Лабораторный референс имеет приоритет. |

### 2. Что считать признаком

1. Гемолиз: ЛДГ выше верхней границы, непрямой билирубин выше, гаптоглобин ниже, ретикулоциты выше. Достаточно одного признака или нужно сочетание? Предложение: «под подозрением», если снижен гаптоглобин и повышен хотя бы один из ЛДГ, непрямого билирубина, ретикулоцитов. — Решение:

   **Не считать гемолизом один показатель. «Подозрение на гемолиз»: есть анемия и минимум два из четырёх признаков — ЛДГ выше ULN, непрямой билирубин выше ULN, гаптоглобин ниже LLN, ретикулоциты выше ULN. «Сильное подозрение»: низкий гаптоглобин и минимум один из остальных трёх признаков. При отсутствии анемии показывать только «есть признаки, требующие проверки», без вывода об анемии.**

2. Ретикулоциты: в % или в абсолютных значениях (×10⁹/л)? В учебном наборе только %. Нужен ли ретикулоцитарный индекс с поправкой на гематокрит? — Решение:

   **Предпочтительно использовать абсолютное число ретикулоцитов (×10⁹/л). Пока в наборе есть только %, использовать процент и при анемии считать скорректированный процент: Retic_corr = Retic% × Hct пациента / Hct нормы. Для взрослых принять Hct нормы 0,45 у мужчин и 0,42 у женщин. RPI не использовать как обязательный признак до добавления абсолютного числа и валидации.**

3. Церулоплазмин: значим только «ниже» (вместе с медью — дефицит меди) или «выше» тоже (растёт при воспалении и беременности — нормальный результат не исключает дефицит)? — Решение:

   **Для дефицита меди значимо только снижение церулоплазмина вместе со снижением меди. Повышение не использовать как самостоятельный диагноз; сохранять как контекстный признак воспаления/беременности. Нормальный церулоплазмин не исключает дефицит меди.**

### 3. Что показывать

1. Врачу: «под подозрением: гемолиз (гаптоглобин …, ЛДГ …)» и предложение досдать недостающие из четырёх анализов. Так? — Решение:

   **Да. Показывать статус, фактические значения, использованный референс и недостающие показатели. Формат: «Подозрение на гемолиз: гаптоглобин …, ЛДГ … . Не оценены: … . Рекомендуется досдать недостающие показатели и сопоставить результат с ОАК и мазком периферической крови».**

2. Пациенту: только «обсудите с врачом показатели разрушения эритроцитов», без названий и чисел? — Решение:

   **Да. Пациенту показывать нейтральный текст: «Есть показатели, которые требуют обсуждения с врачом в связи с возможным изменением обмена или разрушения эритроцитов». Не показывать самостоятельный диагноз и сложные пороги без врачебного контекста.**

3. Снижает ли «под подозрением: гемолиз» уверенность уровня 2 (сейчас по правке 7 уверенность не выше «средней» при любом «подозрении»)? — Решение:

   **Да. При любом статусе «под подозрением» максимальная уверенность — средняя. Если отсутствует хотя бы один ключевой показатель или используется fallback вместо лабораторного референса, максимальная уверенность — низкая/средняя.**

### 4. Локальные референсы и жёсткие рамки

1. Значения врача — по умолчанию. Если лаборатория задаёт свои, они заменяют значения по умолчанию или показываются оба с предупреждением о расхождении? — Решение:

   **Референс лаборатории заменяет значение по умолчанию для флагирования. Значение по умолчанию сохранять в аудите, но не использовать для медицинского вывода, если доступен локальный референс.**

2. Текст предупреждения, например: «Используются референсы лаборатории, а не значения по умолчанию проекта; проверьте единицы и метод». Показывать всегда при локальных значениях или только при расхождении больше N % (какое N)? — Решение:

   **Показывать всегда при использовании локального референса: «Использованы референсные интервалы лаборатории. Они имеют приоритет над значениями по умолчанию проекта; проверьте единицы, метод и возрастно-половую группу». Дополнительное предупреждение о расхождении показывать при отличии более 10%; этот порог только интерфейсный.**

3. Жёсткие рамки (см. выше) редактировать только в конфигурации или нужна настройка на странице? Какие рамки поставить? — Решение:

   **Редактировать только в конфигурации. На странице оставить только отображение единиц и ошибки валидации. Сохранить рамки: ЛДГ 3–50 000 Ед/л; непрямой билирубин 0–1 000 мкмоль/л; гаптоглобин 0–10 г/л; ретикулоциты 0–40%; церулоплазмин 0,01–2 г/л.**

### 5. Беременность

Применять ли эти референсы у беременных? Сейчас у беременных не оценивается только ферритин; гаптоглобин, церулоплазмин и ретикулоциты при беременности меняются. — Решение:

**Не применять обычные взрослые референсы у беременных. Использовать референс из лабораторного бланка или валидированный интервал по триместру. При отсутствии такого референса не флагировать ЛДГ, гаптоглобин, ретикулоциты и церулоплазмин автоматически; выводить «не оценено — отсутствует референс для беременности» и снижать уверенность. Непрямой билирубин также оценивать по локальному/триместровому референсу.**

## Источники

- СМ-Клиника: верхняя граница непрямого билирубина у взрослых до 16,4 мкмоль/л.
- Гемотест: референс ЛДГ у взрослых мужчин 135–225 Ед/л, у женщин 135–214 Ед/л.
- ИНВИТРО: ретикулоциты 6,8–18,6‰ у взрослых; церулоплазмин — половые и возрастные референсы.
- Merck Manual, AAFP, BMJ: сочетание ретикулоцитоза, повышения ЛДГ и непрямого билирубина со снижением гаптоглобина поддерживает гемолиз.
- ISO 15189 / руководства по лабораторным референсам: локальный интервал, валидированный для метода и популяции, имеет приоритет.
