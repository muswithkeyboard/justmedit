# Рабочие решения по вопросам врачу — 04.10.2026

Статус: рабочие решения капитана (подготовлены с ИИ-ассистентом). Врач команды подтверждает или правит до предпитчинга.
Принцип: сервис не утверждает больше, чем можно подтвердить источником; «не оцениваю, вот что досдать» лучше числа без российского источника.

1. **Анемия воспаления и группа кейса.** В пяти группах — `unexplained_anemia` (дефицита нутриентов нет). Врачу на экране показывать класс «анемия воспаления», а не «неясного генеза; причина: воспаление». При воспалении и признаках дефицита железа (ферритин ниже 70, низкое НТЖ или Ret-He) — «возможна железодефицитная анемия на фоне воспаления» (кейс относит такие случаи к ЖДА). Скрытый дефицит отдельной группой не делать: `healthy` плюс отдельное поле. Вопрос наставнику остаётся.
2. **Пороги.** _Отменено п. 10 в части чисел: B12, активный B12 и гомоцистеин оцениваются числом по NICE NG239, серая зона общего B12 — 180–350 пг/мл._ B12, активный B12, гомоцистеин — числом не оценивать: «в КР РФ числового порога нет; оценка по референсу лаборатории»; пороги зарубежных национальных руководств (NICE, BCSH) выключены. Флаг «B12 требует функционального подтверждения» — по неуверенности модели (общий B12 сдан, функциональные маркеры не сданы, вероятность участия B12 в полосе 0,15–0,85). B6, медь, ТТГ — оставить, подпись «референс лаборатории». рСКФ 60 и 30 — оставить (стадии С3 и С4 ХБП; по тексту КР РФ не сверено — подтвердить).
3. **Блок «срочно».** Оставить три порога. Hb ниже 80 (беременные — ниже 70) подписать «тяжёлая анемия по ВОЗ»; лейкоциты ниже 2 и тромбоциты ниже 50 — «выбор проекта». Пациенту — «обратитесь к врачу сегодня», без вызова скорой.
4. **Точка направления на ферритин.** 30 % (находим 77 % случаев, подтверждается почти каждое пятое направление). Переключатель 20 / 30 / 40 оставить.
5. **Референсы ЛДГ, непрямого билирубина, гаптоглобина, ретикулоцитов, церулоплазмина.** _Отменено п. 10 и 11: референсы по умолчанию введены (числа — п. 11)._ Чисел не вводить. В чек-листе — «сдан, оценка по референсу лаборатории» или «не сдан».
6. **Стадия дефицита железа и тактика.** `iron_stage` не делать. Тактика врачу — одна строка: «лечение — по клиническим рекомендациям Минздрава, дозы прототип не приводит».
7. **Восемь золотых случаев.** Решает только врач. Проверить отдельно: случай с рСКФ около 29 должен давать в заголовке «под подозрением: почки».
8. **Правила.** Индекс Ментцера — только при микроцитозе, как подсказка: «меньше 13 — вероятнее носительство β-талассемии; подтверждение — электрофорез гемоглобина»; пациенту не показывать. Граница MCV 100 — оставить. Ферритин у беременных — не оценивать (для них только уровень 1). Серая зона B12 — без чисел (п. 2). «Без найденного дефицита» переименовать в «дефицит по сданным анализам не найден — чек-лист исключений». Гемолиз в чек-листе — «не проверено», пока нет референсов. _Отменено п. 10 и 11 в части B12 и гемолиза: серая зона B12 — 180–350 пг/мл по NICE NG239; гемолиз — по сочетанию признаков (п. 11)._
9. **Низкое НТЖ (ниже 17,8 %) при нормальном ферритине.** Считать находкой: «возможен функциональный дефицит железа; уточнить СРБ, Ret-He или sTfR»; в чек-листе железо — «под подозрением». Оговорка: показатель колеблется в течение дня, один результат не решает.

Дополнительно (решения капитана): п. 6.2 Положения закрыт — план и набор NHANES созданы после старта, ночью работать можно. Файл кейса в текстах называть «учебный набор кейса (840 строк)», не «синтетический». Публичная ссылка на демо — на сервере команды.

10. **Референсы по умолчанию и пересмотр правки 1 (решение капитана 04.10, после предложения врача).** Таблица `docs/facts/reference_table.md` — референс проекта по умолчанию для всех показателей (в т. ч. ЛДГ 120–250 Ед/л, непрямой билирубин 3–17 мкмоль/л, гаптоглобин 0,3–2,0 г/л, ретикулоциты 0,5–2,5 %, церулоплазмин 0,20–0,50 г/л — _эти пять референсов заменены п. 11_). Локальные референсы лаборатории могут их переопределять — тогда в отчёте врачу предупреждение. Жёсткие рамки ввода редактируются в конфигурации. B12, активный B12, гомоцистеин — числом по NICE NG239 (общий B12 <180 нг/л дефицит, 180–350 неопределённо; активный B12 <25 дефицит, 25–70 неопределённо; гомоцистеин >15) с подписью «зарубежный источник; в КР РФ числового порога нет». Отменяет п. 2 и п. 5 выше в части чисел. Ожидает подтверждения врачом.

11. **Ответы врача команды 04.10.2026 по ЛДГ, непрямому билирубину, гаптоглобину, ретикулоцитам, церулоплазмину** (файл с ответами — `medic_answers_references.md`; уточняет п. 10).
    - **Референсы по умолчанию (для взрослых; лабораторный референс имеет приоритет):** ЛДГ М 135–225, Ж 135–214 Ед/л (Гемотест); непрямой билирубин 0–16,4 мкмоль/л (СМ-Клиника); гаптоглобин 0,83–2,67 г/л — запасной, не универсальный российский норматив: без референса лаборатории вывод сопровождается предупреждением; ретикулоциты 0,68–1,86 % (ИНВИТРО, 6,8–18,6 ‰); церулоплазмин М 0,15–0,30, Ж 0,16–0,45 г/л (ИНВИТРО). Абсолютное число ретикулоцитов (34–102 ×10⁹/л) предпочтительно, но в учебном наборе его нет — не добавлено.
    - **Гемолиз:** один показатель — не гемолиз. При анемии минимум два из четырёх признаков (ЛДГ выше, непрямой билирубин выше, гаптоглобин ниже, ретикулоциты выше) — «подозрение на гемолиз»; низкий гаптоглобин и хотя бы один из остальных — «сильное подозрение». Без анемии — только «есть признаки, требующие проверки», без вывода об анемии. Ретикулоциты при анемии — скорректированный процент: ретикулоциты % × Hct / Hct нормы (45 % у мужчин, 42 % у женщин); RPI не используется. Врачу — статус, значения, использованный референс, «не оценены: …», «досдать недостающие и сопоставить с ОАК и мазком периферической крови». Пациенту — нейтрально: «Есть показатели, которые требуют обсуждения с врачом в связи с возможным изменением обмена или разрушения эритроцитов».
    - **Уверенность уровня 2:** при любом «под подозрением» — не выше средней; при подозрении на гемолиз и недостающем ключевом показателе или оценке по референсу проекта вместо лабораторного — не выше низкой.
    - **Медь:** значимо только снижение церулоплазмина вместе со снижением меди; повышение — контекст воспаления или беременности; нормальный церулоплазмин дефицит меди не исключает.
    - **Локальные референсы:** заменяют значение по умолчанию; значение по умолчанию остаётся для аудита. Предупреждение всегда: «Использованы референсные интервалы лаборатории. Они имеют приоритет над значениями по умолчанию проекта; проверьте единицы, метод и возрастно-половую группу»; при отличии границы больше 10 % — отдельная строка со значением по умолчанию (порог интерфейсный).
    - **Жёсткие рамки** — только в конфигурации (без изменений).
    - **Беременность:** обычные взрослые референсы не применять; без референса бланка или триместра — «не оценено — отсутствует референс для беременности». При беременности по-прежнему работает только уровень 1.
