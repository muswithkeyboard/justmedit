# ADR 0008. «Где сдать рядом» вместо цен; выгрузка отчёта в DOCX и PDF

Дата: 04.10.2026.

## Контекст

- Решение пользователя 04.10.2026: в отчёте вместо цены анализа показывать, где его сдать рядом: определить
  положение, дать выбрать точку на карте и показать ближайшие пункты. Отчёт — скачать в DOCX или PDF.
- Неизменные ограничения: сервис ничего не хранит и наружу не ходит; координаты человека — персональные данные,
  их нельзя отправлять ни на сервер, ни третьим лицам без явного действия человека.
- Выбор пользователя из вариантов: «свой список пунктов + карта OpenStreetMap» вместе со «ссылками на Яндекс Карты».

## Решение

1. **Цены из текстов отчётов убраны** (`config/texts_ru/*.yaml`, `reports/doctor.py`, `reports/patient.py`).
   Пометка «в рознице недоступен» осталась. Поле `price_rub` в ответе API сохранено (контракт заморожен), цены
   по-прежнему используются внутри расчёта прироста информации и в экономике скрининга (`docs/metrics`).
2. **Свой список пунктов**: `static/labs/labs_msk.json` — 1 062 пункта 15 сетей лабораторий Москвы и области,
   выгрузка OpenStreetMap (ODbL) на 04.10.2026 09:55 UTC, `scripts/build_labs.py` (запрос в скрипте, фильтр:
   только сети лабораторий; учебные заведения и прочие лаборатории отбрасываются). Выгрузка — вручную, один раз;
   сервис во время работы в OSM не ходит.
3. **Ближайшие считаются в браузере** (формула гаверсинусов, 5 ближайших). Положение — `navigator.geolocation`
   по кнопке «Определить моё положение» (заголовок `Permissions-Policy: geolocation=(self)`) или щелчком по карте.
   Координаты не уходят ни на сервер, ни в ссылки.
4. **Карта** — Leaflet 1.9.4 из `static/vendor/leaflet` (BSD-2, хэши сверены с leafletjs.com), загружается
   только по кнопке «Выбрать на карте». Подложка — картинки `tile.openstreetmap.org` (CSP `img-src` дополнен
   этим адресом; скрипты и стили — только свои). Картинкам подложки браузер отправляет только origin страницы
   (`referrerPolicy: strict-origin`): этого требует политика OSM. По запрошенным квадратам подложки сервер
   OSM видит, какой район смотрят, — поэтому карта не открывается сама; без неё список ближайших тоже работает.
5. **Ссылки на Яндекс Карты** — поиск «сдать анализ <название>» и маршрут до пункта (`rtext=~широта,долгота` —
   координаты пункта, точку старта определяют сами карты). Открываются в новой вкладке по нажатию,
   `rel="noopener noreferrer"`, без координат человека.
6. **DOCX** собирается в браузере (`static/export.js`): Office Open XML в ZIP без сжатия, CRC-32 — свой код,
   без библиотек и без запроса на сервер. Скачивается открытая вкладка: «Отчёт врачу» или «Памятка пациенту»
   (шапка, вывод, таблица показателей, разделы отчёта, выбранные ближайшие пункты).
   **PDF** — через окно печати браузера («Сохранить как PDF») со стилем печати: только открытая вкладка,
   «Подробнее» раскрыто, ближайшие пункты списком без карты.

## Рассмотрено и отвергнуто

- Живой поиск пунктов через Overpass API из браузера — координаты человека уходили бы третьей стороне при
  каждом поиске; покрытие лучше, но это нарушает приватность.
- Карта Яндекса (JS API) — нужен ключ и внешний скрипт на странице; CSP пришлось бы открыть для скриптов.
- Офлайн-подложка (свои квадраты карты) — сотни мегабайт ради демо.
- PDF на сервере (reportlab и шрифты с кириллицей) — новая зависимость и отчёт с ПДн на сервере; окно печати
  браузера даёт тот же результат.

## Последствия

- Список — только Москва и область и только то, что есть в OSM: часть пунктов не размечена, у большинства нет
  адреса (показываем название, часы, расстояние по прямой и маршрут). Если ближайший пункт дальше 40 км —
  страница предлагает поиск на Яндекс Картах. Обновление списка: `python3 scripts/build_labs.py --fetch`.
- Подложка карты требует интернета у пользователя; без него работает список ближайших и ссылки.
- В документации «наружу ничего не ходит» уточнено: сервис — нет; страница — только подложка карты по кнопке.

## Дополнение 04.10.2026: средняя цена в выбранном регионе

Решение пользователя: показывать среднюю цену исследования в выбранном регионе. Регион выбирается списком или
определяется по выбранной точке (`config/prices.yaml → regions`: название и рамка). Цены есть только для Москвы
(медиана по 2–4 лабораториям на 03.10.2026, без взятия крови); для Московской области показываются они же с
оговоркой, для других регионов — «цен нет, уточните в лаборатории». Цена — в карточке «Что досдать», сводкой с итогом
и стоимостью взятия крови в блоке «Где сдать рядом», в DOCX и PDF. В текстах отчётов на сервере цен по-прежнему нет.

## Дополнение 04.10.2026, вечер: подложка карты

Решение пользователя — светлая подложка CARTO без надписей. CARTO без ключа API отдаёт вместо карты плитку
с надписью о ключе (проверено 04.10.2026), поэтому подложка осталась OpenStreetMap (`tile.openstreetmap.org`),
а светлый приглушённый вид даёт фильтр CSS (`.nearby__tiles` в `static/app.css`). Надписи в углу карты выключены;
авторство OpenStreetMap (ODbL) — строкой под картой. Для CARTO с ключом достаточно сменить адрес подложки
в `static/app.js` и CSP `img-src`.
