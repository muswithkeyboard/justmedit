# ADR 0003. Скрининг на NHANES со стандартизацией по справочнику лаборатории

Принято 04.10.2026 (волна 3 прежней версии, тег `prepitch`). Переписано 04.10.2026 (волна 4) под базовый вариант
(ADR 0006); числа — из `docs/metrics/screen_metrics.json` базового варианта.

## Контекст

Скрытый дефицит железа часто без анемии: среди женщин 18–49 с ферритином <15 мкг/л анемии нет у 45,6 %
(n = 388), с ферритином <30 — у 71,2 % (n = 916; тест NHANES 2017–2023, веса NHANES;
`screen_metrics.json` → `cohort.deficient_without_anemia_test_weighted`).

Учебный набор кейса для скрининга не годится: модель кейса по одному ОАК даёт AUROC скрытого дефицита 0,897
(`case_metrics.json`), а модель, обученная на реальных людях, на строках кейса без анемии — 0,676 (n = 195;
`screen_metrics.json` → `case_transfer`). Набор кейса «прозрачнее» реальных людей. Нужны реальные люди
с ферритином и полным ОАК. Такой набор — NHANES (США): 22 752 небеременных взрослых с полным ОАК и ферритином.

В NHANES сменился анализатор: медиана RDW 12,5–12,7 % в 1999–2012 и 13,5–13,6 % с 2013 года. Модель на сырых
значениях завышает риск: у женщин 18–49 для ферритина <30 предсказано в среднем 0,422 при наблюдаемых 0,289
(без весов; `calibration_shift`).

## Решение

- Отдельная модель `models/screen-v1/`: P(ферритин <15) и P(<30) по ОАК, возрасту и полу. Область: 18+,
  не беременные, без анемии по ВОЗ, ферритин не сдан (`metadata.json` → `scope`).
- ОАК стандартизуется: z = (x − медиана) / (q75 − q25) по полу, без меток. При обучении — внутри цикла NHANES;
  при применении — по справочнику лаборатории `config/lab_reference.yaml` (по умолчанию `default`).
  Справочник своей лаборатории строит `deficitlens lab-reference` по выгрузке ОАК — без ферритина.
- Проверка временная: обучение 1999–2016 (14 811 человек без анемии), тест 2017–2018 и 2021–2023
  (5 728 человек без анемии — правка 12; 6 461 — это тест вместе с людьми с анемией).
- Главная цифра — AUC внутри группы женщин 18–49, не общий AUC.
- Порог направления на ферритин считается по проверенной группе (верхние 30 % женщин 18–49) и применяется ко всем
  (правка 5; `config/screen_thresholds.yaml` → `threshold_group: F18-49`).
- При вводе без ферритина рекомендацию ферритина даёт только скрининг (`next_test.py`, п. 1); модель кейса
  по одному ОАК вероятность скрытого дефицита не показывает (правка 4): две модели не спорят на экране.

## Статус

Принято. Реализовано в базовом варианте; метрики совпали с прототипом
(`screen_metrics.json` → `prototype_check.identical: true`).

## Последствия

- Женщины 18–49 без анемии, тест (n = 2 180): AUC 0,822 (95 % ДИ 0,797–0,855; 168 случаев) для ферритина <15
  и 0,727 (0,707–0,749; 629 случаев) для <30. Только Hb + возраст + пол — 0,754 и 0,661.
- После стандартизации калибровка у женщин 18–49 для <30: 0,303 против наблюдаемых 0,289; AUC не падает
  (0,717 на сырых, 0,727 после).
- При тех же 14,8 % направлений, что у правила «MCV <80, или MCH <27, или RDW >14,5», модель находит 57,9 %
  случаев ферритина <15 против 51,0 % у правила: +6,9 п.п. (95 % ДИ 0,6–13,9; бутстрэп, B = 500).
- У женщин 50+ и у мужчин преимущество перед правилом не показано (`rule_comparison` → `model_better: false`);
  у мужчин для <15 случаев меньше 15 — метрика не считается. Результат для этих групп помечается.
- Перенос на российскую клинику сводится к выгрузке ОАК самой лаборатории — без ферритина. Это проверено только
  на смене анализатора внутри NHANES; для России нужна выборка с ферритином.
- Справочник нужно строить по неотобранному потоку взрослых. На строках кейса справочник `default` даёт AUC 0,714
  для <30 (`case_transfer`); собственный справочник по файлу кейса в прежней версии дал 0,561
  (тег `prepitch`) — в метриках базового варианта этого сравнения нет.
- При неполном ОАК скрининг считает по запасной модели «только гемоглобин».
- Данные США: распространённость и экономика — иллюстрация, не оценка для России.

## Отвергнутые варианты

- **Скрининг по модели кейса** — обучена на учебном наборе и завышает качество (0,897 против 0,676 при переносе).
- **Сырые значения ОАК** — ломается калибровка при смене анализатора.
- **Стандартизация с ферритином или метками** — у клиники при внедрении ферритина нет.
- **Порог «верхние 30 % своей группы»** — у мужчин и женщин 50+ это вероятность ниже 1 % (правка 5).
- **Общий AUC по всем взрослым (0,887 / 0,844) как главная цифра** — завышен различиями по полу и возрасту.
