# MedITron 2026 — правила, которые влияют на работу (выписка из Положения)

Источник: страница https://meditron.sechenov.ru/regulation (сохранена пользователем 04.10.2026) и расписание с сайта.

| Пункт | Что сказано | Что это значит для нас |
|---|---|---|

Расписание (сайт): 4 октября — 11:00 мастер-класс, 17:00 предпитчинг и наставники. 5 октября — 14:00 Code Freeze, 15:00 Prez Freeze, 16:00 защита, 19:00 оценки, 20:00 награждение. По Положению презентация входит в комплект к 14:00; про 15:00 уточнить у трекера.
