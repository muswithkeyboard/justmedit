# Дорожная карта Justmedit: чего нет в хакатонной версии

Хакатонная версия Justmedit: без входа — расчёт без хранения (ADR 0005); в личном кабинете (ADR 0009) — SQLite,
значения анализов зашифрованы (Fernet), журнал доступа врачей, удаление аккаунта, доступ врачу по ссылке на срок.
Ниже — то, что нужно для промышленной версии и в хакатонную не входит.

| Блок | Что в промышленной версии | Что есть сейчас |
|---|---|---|
| Хранение | PostgreSQL, несколько копий кабинета за балансировщиком, изоляция клиник (RLS, роли) | SQLite в одном процессе: кабинет — один экземпляр; расчёты без входа масштабируются репликами |
| Резервные копии | Резервные копии базы кабинета и проверка восстановления | Нет: том `jm-data` — единственная копия, удалённое не восстанавливается |
| Вход | ЕСИА (Госуслуги), второй фактор, восстановление пароля | Логин и пароль (scrypt), лимит попыток, смена пароля, «выйти везде» |
| Организации | Разграничение по клиникам, администратор клиники, учёт врачей организации | Роли «пациент» и «врач»; врач видит только пациентов, открывших ему доступ по ссылке |
| Медицина | Абсолютное число ретикулоцитов (34–102 ×10⁹/л, ответ врача, `docs/review/medic_decisions.md`, п. 11); возрастные референсы церулоплазмина; пороги и тексты, утверждённые врачом | Ретикулоциты — только в %; у церулоплазмина только половые референсы; пороги — рабочие решения капитана |
| Ввод | Рукописные бланки, исправление перспективы снимка, проверка на реальных PDF Инвитро, Гемотеста, KDL, Хеликса, CMD | Фото и скан-PDF — локальный Tesseract (ADR 0007); PDF любой лаборатории проверен на реальном PDF ЕМИАС и придуманных бланках |
| Встраивание | Виджет для сайта клиники, вебхуки о готовности, фоновый worker для пакетов | API с ключом и Bearer-токеном, `GET /api/v1/openapi.json`, страница `/developers`, мини-сайт клиники |
| Стандарты | FHIR, СЭМД, коды ФСЛИ | Коды ФСЛИ не удалось получить из открытого источника (`docs/facts/FACTS.md`) |
| Соответствие закону | Путь к 152-ФЗ (согласие на обработку специальных категорий ПДн, модель угроз, аттестация), регистрация ПО как медицинского изделия | Шифрование полей, журнал доступа врачей, удаление аккаунта по запросу; плашка «Не вводите персональные данные» (`docs/security.md`) |
| Эксплуатация | TLS и обратный прокси в репозитории, мониторинг, хранилище ключей (KMS), смена ключа API без перезапуска, песочница для клиник | TLS — на обратном прокси сервера команды (README, «Публикация по ссылке»); ключ шифрования — `DL_DATA_KEY` или `DL_DATA_KEY_FILE` |

Порядок перехода: PostgreSQL и резервные копии → вход (ЕСИА, второй фактор) и разграничение по организациям →
медицинские доработки вместе с врачом → встраивание и стандарты → соответствие закону → эксплуатация и песочница
для клиник.
