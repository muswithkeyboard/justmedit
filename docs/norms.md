# Пороги и источники

Этот файл создаёт `scripts/gen_norms_doc.py` из `config/norms_ru.yaml`. Правьте конфигурацию и запускайте скрипт заново; сам файл руками не правьте.

Версия конфигурации: `2026-10-04c`.

Это пороги показа и правил. Границы, которые выучила модель, здесь не хранятся: они лежат в `models/` и подписываются как «граница по данным набора», а не как порог ВОЗ.

Все значения — черновик до проверки врачом команды. Статус «проверено по первоисточнику» значит только то, что число сверено с текстом источника; уместность порога для конкретного пациента решает врач.

## Правило источников

Решение: команда проекта, 04.10.2026; B12, активный B12, гомоцистеин — по NICE NG239, ожидает подтверждения врачом.

- Пороги берутся из российских документов (клинические рекомендации Минздрава, приказы), из текста кейса и из руководств ВОЗ. ВОЗ прямо назван в кейсе.
- Пороги из зарубежных национальных руководств (NICE, BCSH) по умолчанию не применяются. Такие записи помечены `origin: foreign`.
- Сейчас `policy.use_foreign: false` — глобально зарубежные пороги выключены.
- Исключение — записи из `policy.foreign_allowed`: Витамин B12 общий, Активный B12 (голотранскобаламин), Гомоцистеин. По решению капитана 04.10.2026 (`docs/review/medic_decisions.md`, п. 10; пересмотр правки 1) B12, активный B12 и гомоцистеин оцениваются числом по NICE NG239 с подписью «зарубежный источник; в КР РФ числового порога нет»: общий B12 < 180 пг/мл (= нг/л) — дефицит, 180–350 — серая зона (флаг «B12 требует функционального подтверждения» и досдать активный B12 и гомоцистеин); активный B12 < 25 пмоль/л — дефицит, 25–70 — серая зона; гомоцистеин > 15 мкмоль/л — повышен. Ожидает подтверждения врачом команды.
- Метилмалоновая кислота — без диагностического порога: только референс «обычно < 0,30 мкмоль/л, зависит от метода».
- Если запись B12 убрать из `foreign_allowed`, «пограничный B12» определяется без порога: общий B12 сдан, функциональные маркеры (активный B12, ММК, гомоцистеин) не сданы, а модель не уверена. Тогда движок ставит флаг `b12_gray_zone` и предлагает активный B12 или гомоцистеин (`engine.py`, функция `_b12_flag`; полоса неуверенности — `config/class_mapping.yaml → model_flags.b12_uncertain`).
- Выключенный показатель в таблице значений получает статус «неизвестно» и подпись «числового порога в КР РФ нет; оценка по референсу лаборатории».

## Примечания из конфигурации

- **Гемоглобин.** В КР «Железодефицитная анемия» 2024 дана норма: 120–140 г/л у женщин, 130–160 г/л у мужчин.
- **Гемоглобин.** Пороги ВОЗ 2024 даны для 15–65 лет; старше 65 лет применяются по аналогии.
- **Блок «срочно».** Порог гемоглобина — тяжёлая анемия по ВОЗ; пороги лейкоцитов и тромбоцитов и сама срочность — выбор проекта.
- **С-реактивный белок (СРБ).** Порог СРБ > 5 мг/л ВОЗ приводит в замечаниях о поправке ферритина в обследованиях населения; для отдельного пациента — «оценивать маркеры воспаления вместе с ферритином».
- **Ферритин.** В КР РФ 2024 числового порога ферритина для диагностики у взрослых нет.
- **Ферритин.** У беременных ферритин не оценивается: для них только уровень 1 (решение команды проекта 04.10.2026); оценку проводит врач, ведущий беременность.
- **Насыщение трансферрина железом (НТЖ).** нижняя граница референса КР: 17,8–43,3 %.
- **Растворимые рецепторы трансферрина (sTfR).** порог зависит от метода; оценивать по референсу лаборатории.
- **Витамин B12 общий.** в КР РФ числового порога нет; NICE NG239 — зарубежный источник, применяется по решению команды проекта 04.10.2026, ожидает подтверждения врачом.
- **Активный B12 (голотранскобаламин).** в КР РФ числового порога нет; NICE NG239 — зарубежный источник, применяется по решению команды проекта 04.10.2026, ожидает подтверждения врачом.
- **Гомоцистеин.** в КР РФ числового порога нет; порог > 15 мкмоль/л — по решению команды проекта 04.10.2026, подпись NICE NG239; неспецифичен (B12, фолаты, B6, ХБП).
- **Метилмалоновая кислота (ММК).** диагностического порога нет: обычно < 0,30 мкмоль/л, зависит от метода; в рознице Москвы отдельным анализом крови недоступна.
- **Фолаты сыворотки.** в тексте КР опечатка в единице; по смыслу нг/мл.
- **Церулоплазмин.** белок острой фазы; оценивается только вместе с медью; нормальный не исключает дефицит меди.
- **Индексы ОАК.** Индекс Ментцера считается только при микроцитозе и показывается только врачу: меньше 13 — вероятнее носительство β-талассемии (подтверждение — электрофорез гемоглобина); больше 13 — скорее дефицит железа, чем носительство; ровно 13 — неопределённо.
- **Анализ истории.** Пороги динамики и сроки «давно» — выбор проекта: в КР РФ и у ВОЗ таких чисел для взрослых нет; ожидают подтверждения врачом.

## Чего нет в российских клинических рекомендациях

- В КР «Железодефицитная анемия» (ID 669) нет числового порога ферритина для диагностики у взрослых. Число 30 в КР относится к латентному дефициту у беременных и к контролю восполнения депо.
- В КР «Витамин-B12-дефицитная анемия» (ID 536) нет числовых порогов B12, активного B12, ММК и гомоцистеина.
- Тексты КР сверены по зеркалам, а не по рубрикатору Минздрава: рубрикатор не отдаёт текст без браузера. Номера и год КР официальным источником не подтверждены. Подробности — `docs/facts/FACTS.md` и `docs/facts/FACTS_recheck.md`.

## Референсы проекта по умолчанию

Референс — это «норма» для статусов таблицы значений («в пределах / ниже / выше референса») и для чек-листа исключений (гемолиз, медь). ## Локальные референсы лаборатории

Референсы конкретной лаборатории заменяют референсы проекта по умолчанию для своих показателей. Два способа: набор в `config/norms_ru.yaml → local_references.<имя>` (выбирается полем запроса `lab_reference` — тем же, что выбирает справочник ОАК для скрининга) или поле запроса `reference_ranges` (`{"LDH": {"low": 135, "high": 225, "unit": "Ед/л"}}`; единица — любая допустимая для показателя, пересчитывается в каноническую). При любом локальном референсе в отчёте врачу (первая строка раздела «Ограничения»), в `limitations` и в поле ответа `references.warning` — предупреждение «Использованы референсные интервалы лаборатории. Они имеют приоритет над значениями по умолчанию проекта; проверьте единицы, метод и возрастно-половую группу.» (`config/texts_ru/doctor.yaml → references.local_warning`).
